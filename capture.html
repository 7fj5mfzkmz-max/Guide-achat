Capture depuis votre navigateur

Quand un site bloque la lecture automatique, votre propre navigateur, lui, voit la page. Ce signet lit le nom du modèle sur la page ouverte et le transmet au guide. Rien n’est envoyé à un autre site : le guide s’ouvre avec le résultat.

Étape 1. Touchez « Copier le signet ».

Installer sur iPhone (Safari)

  1. Ouvrez n’importe quelle page, touchez Partager puis Ajouter aux favoris. Nommez-le « Analyser ce modèle » et enregistrez.
  2. Ouvrez vos favoris, touchez Modifier, puis le favori « Analyser ce modèle ».
  3. Dans le champ adresse (URL), effacez tout et collez le signet copié. Validez.

Utiliser

  1. Ouvrez la fiche du téléphone sur Amazon, Fnac, Darty… (dans Safari, pas dans l’application du marchand).
  2. Touchez la barre d’adresse, puis votre favori « Analyser ce modèle » : le guide s’ouvre et analyse le modèle lu.
